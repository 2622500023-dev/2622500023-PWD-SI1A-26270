# Pertemuan 6 – PHP Dasar dan Pemrograman Sisi Peladen

## Langkah Kerja

1. Persiapan Proyek P6
   Menyalin artefak Pertemuan 5 ke folder "pertemuan-06", mempertahankan berkas "style.css", "script.js", dan gambar profil, serta mengubah "index.html" menjadi "index.php".

2. Dasar PHP dan Integrasi HTML
   Mempelajari cara kerja PHP pada sisi peladen, penggunaan tag PHP, komentar, "echo", dan "print" untuk menghasilkan keluaran dinamis.

3. Variabel, Konstanta, dan Tipe Data
   Membuat variabel dan konstanta serta mengenali tipe data "string", "integer", "float", "boolean", dan "NULL" untuk menampilkan informasi profil mahasiswa.

4. Operator PHP
   Menerapkan operator aritmetika, perbandingan, dan logika untuk melakukan perhitungan serta pemeriksaan kondisi semester mahasiswa.

5. Struktur Percabangan PHP
   Menggunakan "if-elseif-else", operator ternary, dan "switch-case-default" untuk menentukan keterangan semester, program studi, status mahasiswa, dan fokus program studi.

6. Perulangan PHP
   Menggunakan perulangan "for" untuk menampilkan lima target belajar dan "while" untuk menampilkan nomor semester.

7. Fungsi Bawaan PHP dan Sintaks Keluaran
   Menggunakan "number_format()" untuk memformat IPK, memeriksa nilai "NULL", menggunakan "date("Y")" untuk menampilkan tahun, serta menerapkan sintaks keluaran singkat "<?= ... ?>".

8. Penyesuaian Formulir
   Mengubah atribut "action" pada formulir dari "index.html" menjadi "index.php".

9. Pengujian dan Pengelolaan Versi
   Menjalankan proyek melalui Laragon dan "localhost", memeriksa hasil keluaran PHP, memperbaiki galat jika ditemukan, memperbarui README, serta melakukan "commit" dan "push" menggunakan Git/GitHub.

## Kesimpulan

Pada Pertemuan 6, halaman web dari Pertemuan 5 dikembangkan menggunakan PHP sebagai bahasa pemrograman sisi peladen. Materi mencakup sintaks dasar PHP, variabel, konstanta, tipe data, operator, percabangan, perulangan, dan fungsi bawaan PHP untuk menghasilkan konten dinamis. Proyek diuji melalui "localhost" dan dikelola menggunakan Git/GitHub. Pemrosesan data formulir menggunakan PHP akan dibahas pada Pertemuan 7.
