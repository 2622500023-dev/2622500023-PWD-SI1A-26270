# Pertemuan - Pemrosesan Formulir dengan PHP, Validasi, Sisi Peladen, dan PRG

## Langkah Kerja

1. Menyiapkan file dari pertemuan sebelumnya dan menjalankan server lokal menggunakan Laragon.
2. Mempelajari pengiriman data menggunakan metode GET dan menguji data melalui URL.
3. Menggunakan metode POST untuk mengirim data formulir.
4. Menambahkan validasi data di sisi server, seperti pemeriksaan kolom kosong, format email, semester, dan pilihan minat.
5. Mengamankan keluaran data menggunakan "htmlspecialchars()" dan menampilkan pesan kesalahan.
6. Menerapkan session dan Post/Redirect/Get (PRG) agar data formulir dapat diproses setelah pengalihan halaman.
7. Melakukan pengujian formulir dan mengunggah hasil pekerjaan ke GitHub melalui commit dan push.

## Hasil Pengujian

- Pengujian GET: Data berhasil dikirim dan ditampilkan melalui parameter URL.
- Pengujian POST: Data formulir berhasil dikirim menggunakan metode POST.
- Pengujian validasi: Sistem memeriksa kelengkapan dan kesesuaian data yang dimasukkan.
- Pengujian keamanan: Karakter HTML pada masukan diproses menggunakan "htmlspecialchars()" agar tidak ditampilkan sebagai kode HTML aktif.
- Pengujian session dan PRG: Data formulir diproses melalui session dan halaman dialihkan kembali setelah pengiriman.
- Pengujian akhir: Seluruh langkah kerja dilakukan mengikuti modul tanpa galat maupun perbaikan.
- Pengujian GitHub: Perubahan pekerjaan berhasil di-commit dan di-push ke repository.

## Kesimpulan

Praktikum P7 membahas pemrosesan formulir menggunakan PHP dengan metode GET dan POST, validasi data, keamanan keluaran, serta penerapan session dan PRG. Seluruh langkah kerja dan pengujian diselesaikan sesuai modul.
