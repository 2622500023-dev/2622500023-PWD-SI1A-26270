# Pertemuan 10 - Pemrograman Web Dasar

## Analisis Kebutuhan Data dan Dasar MySQL Satu Tabel

1. Persiapan Pengembangan

- Menyalin folder pertemuan-09 menjadi pertemuan-10.
- Menjalankan Apache dan MySQL melalui Laragon.
- Membuka phpMyAdmin.

2. Analisis Kebutuhan Data

- Mengidentifikasi data yang akan disimpan dari formulir kontak.
- Menentukan data nama, email, semester, tanggal, jenis pesan, minat, prodi, dan pesan.
- Menentukan penyimpanan pilihan minat dalam satu kolom.

3. Perancangan Struktur Tabel

- Menentukan nama database "db_pwd_NIM".
- Menentukan nama tabel "tbl_kontak_NIM".
- Merancang 9 atribut beserta tipe datanya.
- Menentukan "id" sebagai primary key dengan AUTO_INCREMENT.

4. Pembuatan Database dan Tabel

- Membuat database dan tabel melalui phpMyAdmin.
- Mengisi nama kolom dan tipe data sesuai rancangan.
- Mengatur "id" sebagai primary key dan AUTO_INCREMENT.
- Memeriksa struktur tabel yang telah dibuat.

5. Memasukkan dan Memeriksa Data Awal

- Memasukkan data awal ke dalam tabel.
- Mempelajari penggunaan perintah SQL INSERT.
- Memeriksa data melalui menu Browse.
- Memperbaiki data apabila terdapat ketidaksesuaian.

6. Ekspor Database

- Mengekspor database dengan metode Quick dan format SQL.
- Menyimpan file dengan nama "db_pwd_NIM.sql" ke folder pertemuan-10.
- Memeriksa isi file ekspor untuk memastikan terdapat perintah CREATE TABLE dan INSERT INTO.

7. Hasil Akhir

Berhasil membuat database dan tabel kontak menggunakan MySQL, memasukkan data awal, serta mengekspor database ke dalam file SQL.
